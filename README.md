# 東京 駅名当てタイピング

[keyx0.net/map/](https://keyx0.net/map/) の「都道府県当てタイピングゲーム」を参考にした、東京の鉄道路線図版タイピングゲームです。

## 遊び方

1. `index.html` をブラウザで開く(ビルド不要・サーバー不要)
2. 「全駅制覇モード」または「100秒チャレンジ」を選んでスタート(スペースキーでも開始・リトライ可)
3. 地図上でオレンジ色に光っている駅の名前をローマ字でタイプする
4. 正解すると自動的に次の駅へ進む
5. `Enter` キーでヒント(読み仮名を1文字ずつ表示)。ヒント1回につき+10秒のタイムペナルティ
6. `Esc` キーでパス(答えを表示して次へ・+10秒)。全駅制覇モードではパスした駅が後でもう一度出題される
7. 入力欄からフォーカスが外れたら、地図やゲーム画面をクリックすると復帰する

### 入力について

- `shi/si`、`chi/ti`、`tsu/tu`、`sho/syo`、`ja/zya`、`っ`(子音重ね/`ltu`/`xtu`)、`ん`(`nn`/`n'`/文脈により `n`・`m`)など、一般的なローマ字の打ち方を受け付ける
- 長音は省略してもよい(例: とうきょう → `toukyou` / `tokyo`)
- 間違えたキーは入力欄に残らず、ミスとして数えられる(BackSpace は不要)
- 日本語入力(IME)がオンのときは警告が表示される

### 表示オプション

- **駅名(漢字)を表示する**: オフにすると駅名を隠し、地図上の位置と路線バッジだけを手がかりに答える上級モードになる
- 自己ベストはモードと表示オプションの組み合わせごとにブラウザ(localStorage)へ保存される

## モード

- **全駅制覇モード**: 収録している全駅をランダム順に1周し、クリアまでのタイムを競う
- **100秒チャレンジ**: 制限時間100秒でできるだけ多く正解する(駅はランダムに繰り返し出題)

## 収録路線・駅

JR山手線(全30駅)を中心に、中央線・総武線、東京メトロ銀座線・丸ノ内線・日比谷線、都営浅草線の主要駅、計59駅を収録しています。

路線図は実際の緯度経度ではなく、覚えやすさを優先した簡略化した模式図です(山手線を環状に配置し、他路線は簡略化した位置関係で描画しています)。正確な路線経路・全駅網羅を意図したものではありません。

## ファイル構成

- `index.html` - 画面構造
- `style.css` - スタイル
- `data.js` - 駅・路線データ(駅名/読み/地図上の座標定義。`romaji` は判定エンジンで表せない慣用表記の別名)
- `romaji.js` - かな→ローマ字の柔軟な入力判定エンジン
- `script.js` - ゲームロジック(地図描画・入力判定・タイマー等)
